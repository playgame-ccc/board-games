⚡ SPモード（全自動おまかせ編集）

音声の盛り上がりと文字起こしをもとに、面白そうな所だけをAIが選んでカット・テロップ・タイトル・タグまで自動で用意します。仕上がりを選んでボタンを押すだけです。

文字起こしはブラウザ内AI（初回のみモデルのダウンロードあり・音声は外部送信されません）。ハイライト選定とタイトル作成は通信でAIを使います。カスタムは「90」や「1:30」の形式で入力でき、180秒以下なら縦ショート仕上げ、超える場合は今のフォーマットのままです。素材の時間・容量に上限はありません（長い素材は30分ごとに分割して解析します。ただし端末のメモリを超える巨大ファイルは失敗することがあります）。結果は「↩ 元に戻す」で取り消せます。

    自動で作る

    音声認識はブラウザ内のAI（Whisper）で行い、音声が外部に送信されることはありません。初回のみモデルのダウンロードに通信が必要で、以後はブラウザ内に保存したモデルを使います。長い発言は読みやすい長さのテロップに自動分割されます。

    上のIN/OUTで範囲を決めて「＋ この範囲をカットに追加」。順番どおりにつながります。

    元の動画の音量 100%

    アフレコ（ナレーション録音）

    00:00.0

    今の再生位置（完成タイムライン上）から通し再生し、マイクの声を録音します。停止すると音声トラックに追加され、プレビューと書き出しに合成されます。イヤホン推奨（スピーカーだと動画の音が録音に混ざります）。初回はマイクの許可が必要です。

    BGMは「ループ」オン、効果音はオフで鳴らす時間を指定。開始位置は「完成動画の時間」（カット後の時間）です。書き出し時にミックスされ、▶で単体試聴できます。音声トラックは作業内容の保存に含まれません。

    書き出せるのは、権利を持っている動画・音声のみです。市販曲をBGMにする場合は利用許諾を確認してください。

    使い方ガイド

    基本の流れ

    ①動画をページにドロップ → ②再生しながらIN/OUTで残す範囲を決めて「＋カットに追加」（タイムラインの山カッコを直接ドラッグでも調整可） → ③「＋テロップ」で文字入れ、画面上をドラッグで配置 → ④「⏵ 通し」で確認して「● つないで書き出す」。

    全自動（SPモード）

    仕上がり時間を選んで「⚡ おまかせで作る」だけで、見どころ選定・カット・テロップ・タイトル・サムネ候補・書き出しまで自動。結果は「↩ 元に戻す」で取り消せます。

    音声からテロップ

    テロップタブの「音声から認識」。初回だけモデルを取得し、以後はブラウザ内保存で通信不要。誤字は行を選んで修正、「この見た目を全行に適用」でデザイン統一。

    PCショートカット

    Space/K 再生　J/L ±1秒　←→ ±1コマ（Shiftで1秒）　I/O イン/アウト　T テロップ追加　Delete 選択削除　Ctrl+Z 元に戻す　Ctrl+S 保存　タイムライン上ホイールで微調整

    アフレコ（ナレーション）

    音声タブの「● アフレコ開始」で、完成タイムラインの今の位置から通し再生しながらマイク録音。停止で音声トラックに追加され、位置合わせも自動です。イヤホン推奨。「元音声↓」で声の間だけ動画音量を下げられます。失敗テイクはトラックの削除で消して録り直し。

    テロップの応用

    「＋常時テキスト」は時間・素材に関係なく全編に出ます（チャンネル名向け）。「この見た目を全行に適用」で音声認識した字幕のデザインを一括統一。一覧上の検索欄で行を絞り込めます。不透明度・縁の太さ・左右揃えは編集欄の下段。

    投稿

    YouTubeカードでタイトル・説明・タグ・字幕(.srt)・サムネ候補を用意。投稿前チェックの「SNS」行がmp4見込みならInstagram・TikTokにもそのまま使えます。ファイル名はタイトルに連動します。

    よくあるつまずき

    ・文字起こしが進まない → 初回のみ通信が必要（以後は保存済み）。／・書き出しがwebmになる → SafariかChrome最新版でmp4に。／・アフレコに動画の音が混ざる → イヤホンを使う。／・音が小さいまま → 一度「⏵ 通し」を再生し直すと戻ります。／・間違えた → ほぼ全ての操作はCtrl+Z（↩）で戻せます。

    1. 動作環境と開き方

    「ノセテロ.html」を保存してダブルクリックするだけで使えます。インストール・登録不要。動画が外部に送信されることはありません。

    ブラウザ編集書き出し備考
    Chrome / Edge 最新◎mp4いちばんおすすめ。全SNS投稿可
    Safari◎mp4Mac / iPadで良好
    Firefox○webmYouTube可・Instagramは要変換

    通信が必要なのは「文字起こしAIの初回取得（約80MB・以後不要）」「新フォントの初回表示」「SPのAI選定」の3つだけ。使える機能は「環境チェックを実行」で確認できます。

    2. 画面の見かた

    • モニター＋タイムライン（固定表示）：黄＝残すカット、緑＝テロップ。山カッコ〈 〉を直接ドラッグでIN/OUT調整、黄色ブロックをタップで区間読込
    • 操作列：再生・通し・コマ送り・IN/OUT・速度・カット追加・テロップ追加
    • 左：SPモード／書き出し／YouTube準備／素材　右：テロップ・カット・音声タブ

    「⏵ 通し」＝カット・速度・つなぎ・BGM・アフレコ込みの完成形プレビュー。書き出し前に一度見るのがおすすめ。

    3. 基本の流れ

    1. 動画をページにドロップ（複数で結合可。上限なし・巨大ファイルは警告のみ）
    2. 残す場面の頭で「〈 IN」、終わりで「OUT 〉」→「＋ この範囲をカットに追加」
    3. 「＋ テロップ」で文字入れ。画面上の文字は直接ドラッグで配置
    4. 「⏵ 通し」で確認 →「● つないで書き出す」

    ほぼ全操作はCtrl+Z（↩ 元に戻す）で30段階まで取り消せます。素材の削除だけは戻せません。

    4. カット編集

    • 並べ替え＝各行の↑↓／修正＝黄色ブロックをタップ→山カッコ調整→「更新」
    • 「複製」＝同じ場面をもう一度（リプレイ）／「削除」「全削除」＝取り消し可
    • 速度×0.25〜×3を区間ごとに設定可。別素材の区間を混ぜれば結合
    • つなぎ目：カット／黒フェード／クロスフェード。「フェード端」で頭と最後が黒からフェード

    5. テロップ

    • 追加：「＋ テロップ」／Tキー。行をタップで編集欄（文字・時間・フォント10種・サイズ・色・縁色・スタイル・左右揃え・不透明度・縁の太さ）
    • ＋ 常時テキスト：全編に出るテキスト（チャンネル名向け）。字幕やチャプターには混ざりません
    • この見た目を全行に適用：デザイン一括統一（常時テキスト除く）
    • 行が多いときは検索欄で絞り込み。Deleteキーで選択行を削除

    6. 音声から自動でテロップ

    1. テロップタブ「音声から自動作成」→ モデルは標準のまま「音声から認識」
    2. 初回のみモデル取得（以後ブラウザ内保存で通信不要）。30分ごとに分割処理・中止可
    3. 1枚24文字以内に自動分割。誤字は行をタップして修正

    音声は端末内処理で外部送信なし。「IN–OUTのみ」で範囲指定認識、.srt/.vtt読込も可。

    7. BGM・効果音

    音声タブ「＋ 音声を追加」（mp3/m4a/wav）。トラックごとに開始位置・音量・ループ・フェードIN/OUT・元音声↓（鳴っている間だけ動画音を25%に）を設定。「試聴」で単体、「⏵ 通し」で合成確認。動画自体の音量は「元の音声」スライダー。

    市販曲は投稿先の利用許諾を確認してください。

    8. アフレコ（ナレーション録音）

    1. イヤホンを着ける（スピーカーだと動画音が録音に混ざります）
    2. 音声タブ「● アフレコ開始」→ 初回はマイク許可
    3. 完成タイムラインの今の位置から通し再生。映像に合わせて話す（レベルメーター表示）
    4. 最後まで再生 or「■ 停止して追加」→ トラック「アフレコ1」として追加（同期自動）
    5. 「⏵ 通し」で確認。失敗テイクはトラック削除で録り直し

    「ナレーション中は元音声を下げる」ONで声の間だけ自動ダック。再生位置を途中に置けば部分録りも可。録音は作業ファイルに保存されないので、同じ回で書き出しまで。

    9. SPモード（全自動おまかせ）

    1. 仕上がり選択：60秒／3分／4分／カスタム（「1:30」形式・180秒以下は縦ショート仕上げ）
    2. 「⚡ おまかせで作る」→ 盛り上がり解析→文字起こし→AI選定→カット＋テロップ2層＋縦設定＋サムネ3案→（ONなら）書き出し
    3. 結果行タップでその区間へジャンプ。「↩ 元に戻す」で丸ごと取り消し

    AI接続不可（ローカル等）でも音量ベース選定で完走します。

    10. 書き出しとSNS対応

    • 出力：自動／16:9／9:16縦／1:1、収め方＝クロップ／全体、画質＝標準／高
    • 「● つないで書き出す」→ 実時間で進行・残り約◯秒を表示。ファイル名はタイトル連動
    投稿先おすすめ形式条件
    YouTube / Shorts16:9 / 9:16（3分以内）mp4・webm可
    Instagram リール9:16（最長3分）mp4のみ
    TikTok9:16mp4（Web投稿はwebm可）

    投稿前チェックの「SNS」行が、いまのブラウザでの形式見込みと可否を自動表示します。

    11. タイトル・字幕・サムネ・チャプター

    • AIで下書き（タイトル案・説明・タグ）。チャプター自動挿入は1時間超も正しい表記
    • 字幕（.srt）はテロップから出力時間で書き出し。YouTube Studioへそのまま
    • サムネ候補3案を自動生成→「この案を保存」で1280×720 PNG。文字差し替え再生成可

    12. 保存と読み込み

    「作業を保存」（Ctrl+S）で .json 保存。「作業を読み込む」または .json をページにドロップで復元。動画本体は含まれないため、同じ動画を先に取り込んでから読み込んでください（ファイル名で自動対応）。

    14. 困ったときは（FAQ）

    症状対処
    文字起こしが進まない初回のみ通信が必要。2回目からはオフライン可。環境チェックでIndexedDBが✓か確認
    webmになりInstagramに上げられないSafariかChrome最新版で書き出すとmp4。投稿前チェック「SNS」行で事前確認
    アフレコに動画音が混ざるイヤホンを使う
    マイクを利用できませんと出るアドレスバー横のアイコンからマイクを許可。埋め込み表示では不可のことあり（ローカルで開けば可）
    動画の音が小さいまま「⏵ 通し」を一度再生し直すと復帰します
    テロップ一覧に行がない検索欄の文字を消す（絞り込み中は件数表示に明記）
    iPhoneの動画（.MOV）が読めない・映らないまず環境チェックの「実行環境」を確認。アプリ内プレビュー（埋め込み）だと制限されるため、HTMLを保存してSafari等で直接開く。それでも不可なら「設定→カメラ→フォーマット→互換性優先」で撮影した動画を使う。エラーに出るコード（1〜4）が原因の手がかりです
    大きい動画で失敗端末メモリが上限。720pの軽い複製で編集するのが確実
    間違えたCtrl+Z。素材削除のみ不可逆

    15. 既知の制限（仕様）

    • 書き出しは実時間。画面を閉じない・タブを切り替えない
    • YouTubeへの自動アップロードは非対応（ファイル＋テキスト＋Studioリンクまで自動）
    • SPのAI選定・AI下書きは通信が必要（不可なら音量ベースへ自動切替）
    • 文字起こしの中止は30分区切りの境界で有効
    • BGMフェードOUTはカット区間ごと（区間が多いときはOFF推奨）
    • アフレコ・BGMの音データは作業ファイルに保存されない
